# Storage-Manager

Aplicação web do Storage Manager, desenvolvida com Next.js, React e TypeScript (frontend), Python (backend). 

## Arquitetura 

- - `frontend`: parte da aplicação que interage diretamente com um usuário 
- - `backend`: parte da aplicação que disponibiliza rotas (APIs) para interação do frontends com o banco de dados 
- - `banco de dados`: Bancos de Dados relacional SQL lite, decidi iniciar o desenvolvimento no banco estático e posteriormente modulariza-lo para que também se adapte um banco não relacional 

## Objetivo 

O objetivo principal é desenvolver um gerenciador de estoque que lide com múltiplos usuários e diferentes tipos de autenticações ao mesmo tempo, além de desenvolver um portifólio sólido dos meus conhecimentos nessas linguagens. 

As ferramentas disponíveis nesse software serão um gerenciador de estoque, um sistema de notificação, um sistema de controle de usuários e permissões, um dashboard com análises de diversos dados do sistema e uma página inicial que será moldável de acordo com a necessidade do usuário. 

Escolhi essa arquitetura e estrutura apenas para demonstrar meus conhecimentos, deixando um pouco de lado modelos e linguagens que tem propósitos mais eficientes.
